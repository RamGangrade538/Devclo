## Prerequisites

- Computer with internet access
- A terminal / command line
- Willingness to learn

## What You'll Need

- Linux/Mac/WSL2 environment
- [GitHub Account](https://github.com/) (Free)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- VS Code with Remote Containers extension

## Daily Structure

Each day includes:
- **Tasks** - Checklist of things to learn/do
- **Resources** - Links to official docs, tutorials, videos
- **Practice Exercise** - Hands-on challenge to reinforce learning
- **Notes** - Space for your personal notes

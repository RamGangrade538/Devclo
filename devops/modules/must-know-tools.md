# 🧰 Must-Know DevOps Tools — GitHub, Docker, K8s, Terraform, Ansible, Grafana & More

> **Hinglish:** Interview + real job me **tools matter karte hain** — is module me jo sabse zyada puchte hain woh hain: **Git & GitHub, Docker, Kubernetes, Jenkins, Terraform, Ansible, Argo CD, Prometheus, Grafana, AWS** — kab, kyun, kaise use karte hain.

## 📖 Overview — Ye Topic Kya Hai

DevOps = kaam **tools se hota hai**. Har tool ek kaam karta hai — jaise DevOps ke **swiss army knife**. Logo expect karte hain ki tum base pe inko jaante ho: git ko version control me, docker ko container build me, k8s ko orchestration me, terraform infra create me, jenkins pipeline me, grafana dashboard me.

Ye module 12 core tools ek hi jagah par concisely: purpose, jab use karein, aur typical interview/test questions.

## 🟢 Beginner — Shuruaat yahan se

- Git basics — `clone`, `add`, `commit`, `push`, `pull`, `merge`, `rebase`.
- Docker — `Dockerfile`, `build`, `run`, `compose` basics.
- K8s — Deploy, Service, Ingress, ConfigMap basics.
- Jenkins — first pipeline (declarative `Jenkinsfile`).
- AWS console — S3, IAM, EC2 explore.
- Grafana — Prometheus + dashboards connect.
- Terraform basics — `init`, `plan`, `apply`.
- Ansible basics — ad-hoc → playbook.

## 🟡 Intermediate — Ab depth me jao

- GitHub — PR, branch protection, Actions.
- Docker — multi-stage build, layers, registry.
- K8s — ConfigMap/Secret, PV/PVC, Helm chart.
- Jenkins — shared library + quality gates.
- Terraform — module + remote state.
- Ansible — roles + inventory by env.
- Argo CD — GitOps sync flow.
- Prometheus — alertmanager + recording rules.
- Grafana — advanced panels + dashboard as code.
- AWS — VPC, EC2, IAM, S3 + cost awareness.

## 🔴 Advanced — Pro bano

- K8s — operators/CRD + RBAC hardening.
- Terraform — workspace + multi-env strategy.
- Ansible — vault + dynamic inventory + Molecule.
- Jenkins — multibranch + agents scaling.
- Argo CD — ApplicationSet + App of Apps.
- Prometheus — federation + distributed tracing.
- Grafana — SLOs + incident view.
- AWS — Well-Architected review + cost/risk.
